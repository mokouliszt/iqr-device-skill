# ポインタ・その他のデバイス詳細仕様

iQ-Rの「その他のデバイス」分類に属する N（ネスティング）, P（ポインタ）, I（割込みポインタ）, J（ネットワークNo.指定）, U（I/O No.指定）, BL（SFCブロック）, TR（SFC移行）の個別仕様。

## ネスティング (N)

- **種別**: -
- **記号**: N
- **デフォルト点数**: 15点（N0〜N14）
- **最大使用範囲**: 変更不可
- **設定単位**: -
- **表記**: 10進数
- **用途**: マスタコントロール命令(MC/MCR命令)で、シーケンス内のインタロック条件のネスト構造を表現
- **動作**: MC命令で指定したNn が ON 条件を確立しているとき、そのN番号以下のシーケンス回路が有効になる
- **バックアップ/リストア**: 不可 / 不可
- **トラッキング転送**: 対象外

## ポインタ (P)

- **種別**: -
- **記号**: P
- **デフォルト点数**: 8192点（**R120CPU, R120ENCPU, R120PCPU, R120SFCPUでは 16384点**）
- **最大使用範囲**: ポインタ設定で変更可
- **設定単位**: -
- **表記**: 10進数
- **用途**: シーケンスプログラムのジャンプ先・サブルーチン先を指定するラベル
- **動作**:
  - **グローバルポインタ**: 全プログラムで共通
  - **ローカルポインタ**: プログラムごとに独立。同じ番号でも別の場所を示す

### ポインタ設定（CPUパラメータ）

`[CPUパラメータ] → [メモリ/デバイス設定]` でグローバル/ローカルの点数配分を変更可能。

### バックアップ/リストア

- **バックアップ/リストア**: 不可 / 不可

### トラッキング転送

- 対象外

### 注意事項

- 同一のローカルポインタ番号(またはポインタ型ローカルラベル)が同一プログラム内で複数箇所に設定されていると、**エラーコード 3303H（ポインタ設定異常、停止）** が発生
- 同様に同一のグローバルポインタ番号(またはポインタ型グローバルラベル)が複数箇所に設定されていると **エラーコード 3302H** が発生
- 命令で指定した行き先のポインタが存在しないと **エラーコード 3380H（ポインタ実行不可、停止）**
- 実行したサブルーチンプログラムにRET命令がない → **エラーコード 3381H**
- メインプログラムのFEND命令の前にRET命令がある → **エラーコード 3382H**
- ローカルポインタとして使用する場合、インデックス修飾は不可

## 割込みポインタ (I)

- **種別**: -
- **記号**: I
- **デフォルト点数**: 1024点
- **最大使用範囲**: 変更不可
- **設定単位**: -
- **表記**: 10進数
- **用途**: 割込みプログラムの先頭ラベル

### 割込みポインタ番号と要因の対応

| 割込みポインタ番号 | 割込み要因 |
|--------------------|-----------|
| I0〜I15 | ユニットからの割込み（割込み機能があるユニットで使用） |
| I28〜I31 | 内部タイマによる割込み（定周期割込み） |
| I44 | ユニット間同期割込み（定周期） |
| I45 | マルチCPU間同期割込み（定周期） |
| I48 | 高速内部タイマ割込み2（I28〜I31より短い間隔指定可能） |
| I49 | 高速内部タイマ割込み1（I28〜I31より短い間隔指定可能） |
| I50〜I1023 | ユニットからの割込み |

### 割込み優先度・優先順位（番号小さいほど高優先）

| ポインタ | 要因 | 優先度 | 優先順位 |
|---------|------|--------|---------|
| I49 | 高速内部タイマ割込み1 | 1 | 1 |
| I48 | 高速内部タイマ割込み2 | 2 | 2 |
| I45 | マルチCPU間同期割込み | 3 | 3 |
| I44 | ユニット間同期割込み | 3 | 4 |
| I31 | 内部タイマ割込み | 4 | 5 |
| I30 | 内部タイマ割込み | 4 | 6 |
| I29 | 内部タイマ割込み | 4 | 7 |
| I28 | 内部タイマ割込み | 4 | 8 |
| I0 | ユニット割込み 1点目 | 5〜8 | 9 |
| I1〜I15 | ユニット割込み 2〜16点目 | 5〜8 | 10〜24 |
| I50〜I1023 | ユニット割込み | 5〜8 | 25〜998 |

### 動作・制約

- 高速内部タイマ割込み(I48, I49) はR04CPU以上で使用可能。R00/R01/R02CPUでは使用不可
- ユニット間同期割込み(I44)・マルチCPU間同期割込み(I45) は対応CPU・バージョン制約あり
- 設定周期は 0.5〜1000ms（I28〜I31）または 0.05〜1000ms（I44, I45, I48, I49）

### バックアップ/リストア

- **バックアップ/リストア**: 不可 / 不可

### 注意事項

- 同一ファイル内で同一の割込みポインタ番号が重複していると **エラーコード 3320H（割込みポインタ設定異常、停止）**
- 割込み入力が発生したのに対応する割込みポインタがない → **エラーコード 33A0H（割込みポインタ実行不可、停止）**
- 実行した割込みプログラムに IRET 命令がない／割込みプログラムでSTOP命令を実行 → **エラーコード 33A1H**
- メインプログラムのFEND命令の前にIRET命令がある → **エラーコード 33A2H**
- 定周期実行タイププログラムでIRET命令またはSTOP命令を実行 → **エラーコード 33A3H**
- イベント実行タイププログラムでIRET命令またはSTOP命令を実行 → **エラーコード 33A4H**
- 割込みポインタとして使用する場合、インデックス修飾は不可

## ネットワークNo.指定デバイス (J)

- **種別**: -
- **記号**: J
- **デフォルト点数**: -
- **表記**: 10進数
- **用途**: リンク専用命令などでネットワークNo.を指定する場合に使用するデバイス
- **使用例**: J1, J2 ... J239 のようにネットワークNo.を直接指定して、専用命令の引数として与える
- **詳細**: `MELSEC iQ-R プログラミングマニュアル(ユニット専用命令編)` 参照
- **バックアップ/リストア**: 不可 / 不可
- **トラッキング転送**: 対象外

## I/O No.指定デバイス (U)

- **種別**: -
- **記号**: U
- **デフォルト点数**: -
- **表記**: 16進数
- **用途**: インテリジェント機能ユニットの専用命令などでI/O No.を指定する場合に使用するデバイス
- **使用例**: U0, U10, U1F のようにユニット先頭I/O番号上位2桁で指定
- **詳細**: `MELSEC iQ-R プログラミングマニュアル(ユニット専用命令編)` 参照
- **バックアップ/リストア**: 不可 / 不可

## SFCブロックデバイス (BL)

- **種別**: -
- **記号**: BL
- **デフォルト点数**: 320点（**R00/R01/R02CPUは 128点**）
- **最大使用範囲**: 変更可
- **設定単位**: -
- **表記**: 10進数
- **用途**: SFCプログラムのブロックを指定する場合に使用。SFC制御命令やエンジニアリングツールによるSFCプログラムの確認(モニタや現在値変更)などでステップNo.を指定する場合にも使用
- **対応CPU**: SFC機能を使用できるCPUユニットのみ。バージョン制約あり
- **詳細**: `MELSEC iQ-R プログラミングマニュアル(プログラム設計編)` 参照
- **バックアップ/リストア**: 不可 / 不可
- **トラッキング転送**: 対象外（ただし両系実行プログラム関連でグローバルラベル経由のSFC情報転送は可）

## SFC移行デバイス (TR)

- **種別**: -
- **記号**: TR
- **デフォルト点数**: 0点
- **最大使用範囲**: 変更可
- **設定単位**: -
- **表記**: 10進数
- **用途**: SFCプログラムの移行条件を指定する場合に使用するデバイス。**移行条件に対してのデバイスコメントとしてのみ使用可能**（実体は持たない）
- **対応CPU**: SFC機能を使用できるCPUユニットのみ
- **詳細**: `MELSEC iQ-R プログラミングマニュアル(プログラム設計編)` 参照
- **バックアップ/リストア**: 不可 / 不可

## 命令ネスト数の上限（参考）

ポインタ・サブルーチン・FOR-NEXT・割込み禁止 (DI) のネスト構造は、それぞれの上限を超えるとエラー：

- サブルーチンプログラムのネスティング上限 → 16重（**エラー 3360H**）
- FOR命令のネスティング上限 → 16重（**エラー 3361H**）
- DI命令のネスティング上限 → 16重（**エラー 3362H**）
- ファンクションブロック(FB)、ファンクション(FUN)のネスティング上限 → 32重（**エラー 3363H**）

## 関連エラーコード（FOR-NEXT等）

- **3340H**: FOR-NEXT命令異常 - FOR命令を実行したのにNEXT命令が実行されなかった、またはNEXTがFORより少ない（END命令実行時に検出）
- **3341H**: FOR-NEXT命令異常 - FOR命令を実行していないのにNEXT命令が実行された、またはNEXTがFORより多い（命令実行時に検出）
- **3342H**: FOR-NEXT命令異常 - FOR命令を実行していないのにBREAK命令が実行された
- **33C0H**: FB/FUN実行不可 - FB/FUN実行完了前に呼出し元プログラムの実行が完了
